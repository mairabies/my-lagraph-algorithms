      18             : // LAGraph_Matrix_Binary_Sum combines an array of matrices into a single matrix
      19             : // C, computing the same result as LAGraph_Matrix_Sum but with a different
      20             : // technique: a pairwise binary reduction tree built from GrB_eWiseAdd, as
      21             : // described in the GraphChallenge "Anonymized Network Sensing" paper (Fig. 3,
      22             : // "Binary Summation of Traffic Matrices").  At each level of the tree the
      23             : // matrices are summed in disjoint adjacent pairs; an unpaired (odd) trailing
      24             : // matrix is carried up to the next level unchanged.  The levels repeat until a
      25             : // single matrix remains.  Each pair-sum uses the binary operator dup, which has
      26             : // the same set-union semantics as the dup operator of GrB_Matrix_build: dup is
      27             : // applied wherever both inputs have an entry, and lone entries pass through.
      28             : // With dup = GrB_PLUS_FP64 (for example) this computes the element-wise sum of
      29             : // all the input matrices.
      30             : 
      31             : // The independent pair-sums within a level are issued concurrently across
      32             : // LG_nthreads_outer threads with OpenMP; each such outer thread calls into
      33             : // GraphBLAS, which parallelizes each GrB_eWiseAdd internally with
      34             : // LG_nthreads_inner threads (the documented two-level model).
      35             : 
      36             : // Memory: a level's intermediate results are only needed as inputs to the next
      37             : // level, so each pair's two inputs are freed as soon as their sum is built.
      38             : // Only the active merge frontier (the current level plus the partially-built
      39             : // next level) is ever resident, rather than every intermediate result at once.
      40             : // This is what makes the tree a memory win: adding two matrices each with N
      41             : // entries yields a matrix with fewer than 2N entries, and the smaller
      42             : // intermediates stay in faster memory.  The original input matrices (level 0)
      43             : // are never freed.
      44             : 
      45             : // Ownership is tracked per working-array slot: ownedW[k] is true iff W[k] is a
